# Estación 9

Proyecto de videojuego desarrollado en Unreal Engine 5.8 para la asignatura de Arquitectura de Videojuegos - Universidad de Boyacá.

## Integrantes
- Juan José Plazas Ochoa
- Laura Estefany Rivera Pérez

---

## Entrega Semana 1
- **Personaje en primera persona**: Caminar, correr (`Shift`), agacharse (`Ctrl`) y saltar (`Espacio`).
- **Sistema de interacción**: Detección con *LineTrace* al presionar la tecla `E`.
- **Puerta interactiva**: Blueprint con bisagra, rotación suave mediante interpolación y sonido de apertura/cierre.
- **Nivel de prueba**: Escenario base de pruebas de Unreal Engine 5.

---

## Requisitos y Ejecución
1. Unreal Engine 5.8
2. Abrir el archivo `EstacionNueve.uproject`
3. Presionar **Play (Alt + P)**
